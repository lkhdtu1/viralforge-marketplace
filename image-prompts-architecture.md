## 1. Couche de Présentation (Frontend)

```

Design Style:
- Modern, minimalist design with a light blue and cyan color palette (#3B82F6, #06B6D4, #E0F2FE)
- Soft shadows and subtle gradients
- Clean typography and generous white space
- Responsive design elements clearly visible (elements reorganizing across devices)
- Professional e-commerce aesthetic

Atmosphere:
- Bright, welcoming, user-friendly
- Emphasis on ergonomics and accessibility
- Modern tech illustration style, similar to Apple or Google design presentations
- Include subtle French text: "Interface Responsive", "Multi-terminaux", "Ergonomie"

Background: Clean white or very light gradient background. The illustration should feel premium and professional, emphasizing the user experience and responsive design capabilities.
```

## Guide d'Utilisation

### Paramètres Recommandés:
- **Format**: 16:9 (1920x1080) ou carré (1080x1080) pour réseaux sociaux
- **Style**: Illustration moderne, style tech/SaaS professionnel
- **Résolution**: Minimum 1920x1080 pour qualité professionnelle

### Outils de Génération:
- **Midjourney**: Ajoutez `--style raw` ou `--v 6` pour un style plus technique
- **DALL-E 3**: Excellent pour des illustrations précises et détaillées
- **Stable Diffusion**: Pour un contrôle fin des détails
- **Adobe Firefly**: Pour des illustrations professionnelles

### Variations de Style:
Pour chaque prompt, vous pouvez ajouter:
- `in the style of modern tech illustration` - Style technique moderne
- `isometric 3D illustration` - Vue isométrique 3D
- `flat design, minimalist` - Design plat et minimaliste
- `cyberpunk aesthetic` - Style cyberpunk (pour backend)
- `clean corporate design` - Design corporate propre

### Conseils:
- Utilisez ces prompts tels quels pour des résultats cohérents
- Pour un style uniforme, utilisez les mêmes paramètres pour les 3 images
- Les couleurs suggérées créent une cohérence visuelle entre les couches
- Les textes en français peuvent être ajoutés après génération si nécessaire
